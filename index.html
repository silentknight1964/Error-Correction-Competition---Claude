Mission Guide

                    
HELP — Grammar Escape Room

                    
A guide to the game, controls, scoring, clues and teacher functions.

                

                
            


            


                

                    
🔐 What is Grammar Escape Room?

                    

                        Grammar Escape Room is an individual English error-correction challenge. Each faulty sentence is treated as a locked room.
                        The player must type the complete corrected sentence to unlock the room, gain energy points and progress through the mission.
                    

                    

                        The game records score, total time, clue use and per-question performance. At the end, the player receives an Escape Certificate
                        and can download a detailed performance JSON file.
                    

                


                

                    
⚙️ Setup Screen

                    

                        
Agent Name: Enter the student's name or codename. It appears on the final certificate and exported results.

                        
Mission File (JSON): Upload a compatible JSON file containing the incorrect sentences, correct answers and hints.

                        
Room Range: Choose which numbered items to play. For example, 1 → 10 plays the first ten rooms only.

                        
Gamemaster Access: Enter the teacher password to activate the hidden teacher information panel during gameplay.

                        
HELP: Opens this guide.

                        
Enter the Escape Room: Starts the selected mission after a valid name, file and room range are provided.

                    

                


                

                    
🧩 How to Solve a Room

                    

                        
The faulty sentence appears in the central question cell.

                        
Type the complete corrected sentence in the answer box.

                        
Press ⚡ Attempt Unlock to check your answer.

                        
If correct, the lock opens, the room is marked as solved, and the Next Room → button appears.

                        
If incorrect, the lock resists and you may try again.

                        
The checker ignores capitalization differences, repeated spaces and final sentence punctuation.

🗝️ Clue System

                    

                        
Clue 1: Gives the first, gentler hint from the JSON file.

                        
Clue 2: Unlocks only after Clue 1 and provides a stronger explanation.

                        
Force Open: Unlocks after Clue 2. It fills in the correct sentence and marks the room as failed rather than independently solved.

                        
Hints must therefore be used in order; stronger help cannot be selected immediately.

                    

                


                

                    
🚪 Room Progress

                    

                        The row of door-shaped indicators shows the current mission progress. The active room is highlighted, solved rooms turn green,
                        and rooms opened with Force Open are marked as failed.
                    

                    

                        The top bar also shows the current score, elapsed time and room number.
                    

                


                

                    
👨‍🏫 Gamemaster Access

                    

                        When the correct Gamemaster password is entered on the setup screen, a hidden teacher panel becomes visible during gameplay.
                        It shows the stored correct sentence, Hint 1 and Hint 2 for the current item.
                    

                    

                        This mode is intended for classroom supervision and checking. In normal student mode, these answers remain hidden.
                    

                


                

                    
🏆 Escape Certificate

                    

                        
After the last room, the final screen shows Energy, Time, Accuracy and Clues Used.

                        
Accuracy counts rooms solved independently. A room opened with Force Open is not counted as independently solved.

                        
The app also awards an Escape Rank:

                        
    
                            
  • 90%+ — Master Escapist
    • 
                            
  • 70–89% — Skilled Agent
    • 
                            
  • 50–69% — Apprentice
    • 
                            
  • Below 50% — Still Locked In
    • 
                        

                    

                


                

                    
📥 Download Intel

                    

                        The Download Intel button exports a JSON performance report containing the student's name,
                        date, total questions, score, total time, accuracy, total hints used and detailed performance for each room.
                    

                    

                        Per-question data includes the faulty sentence, target correction, student's final answer, number of attempts, hints used,
                        whether the item was solved independently and time spent.
                    

                


                

                    
🔄 New Mission

                    

                        The New Mission button returns to the setup screen only after the correct Gamemaster restart code is entered.
                        This prevents accidental loss of the completed result screen.
